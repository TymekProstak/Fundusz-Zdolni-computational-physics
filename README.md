# Fundusz Zdolni – Computational Physics Workshops

Source code and presentations from physics workshops for high school students at the Faculty of Physics, University of Warsaw (UW).

## About the Project

During my high school years, I had the opportunity to participate twice in multi-week computational physics workshops. I worked closely with PhD students at the University of Warsaw, tackling advanced topics in physics chosen by the supervisors.

This repository contains:
* Summaries and descriptions of the chosen research topics.
* Presentations showcasing the results, which I delivered at the conclusion of each workshop.
* Simulation scripts written during the workshops, which have been subsequently refactored and improved.
* Data visualization scripts used to plot and analyze the generated results.

## Projects Included

### 1. Phase Imprinting in Bose-Einstein Condensates
* **Language:** Python
* **Description:** Simulations exploring the dynamics of phase imprinting in Bose-Einstein condensates. 

### 2. Kelvin-Helmholtz Instability
* **Language:** C++
* **Description:** Parallel simulations modeling the Kelvin-Helmholtz instability, a fluid dynamics phenomenon occurring when there is velocity shear in a single continuous fluid or a velocity difference across the interface between two fluids.

## Repository Structure

* `Niestabliność Kelwina-Helmhotza.pptx` - Presentation slides for the Kelvin-Helmholtz instability project.
* `kondesat (1).pptx` - Presentation slides for the Bose-Einstein condensates project.
* `/bose_einstein_condensat/` - Directory containing Python simulation and plotting scripts.
* `/kelvin_hemholtz_instablity/` - Directory containing C++ parallel simulation source code.
